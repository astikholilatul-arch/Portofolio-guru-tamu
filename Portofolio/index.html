Tentang Saya

Dedikasi Belajar & Minat di Dunia Koding

Mengenal lebih dekat perjalanan saya sebagai siswi Rekayasa Perangkat Lunak di SMK Telkom Lampung.

Membangun fondasi teknologi dari ruang kelas hingga karya nyata.

Saya adalah siswi jurusan Rekayasa Perangkat Lunak (RPL) di SMK Telkom Lampung. Ketertarikan saya pada dunia pemrograman bermula dari rasa ingin tahu bagaimana sebuah desain visual dapat dihidupkan melalui kode hingga dapat berinteraksi dengan pengguna secara langsung.

Selama masa belajar di SMK Telkom Lampung, fokus utama saya terpusat pada Front-End Web Development dan perancangan antarmuka pengguna (UI/UX). Saya berpegang pada prinsip bahwa kode yang baik tidak hanya harus berjalan tanpa eror, tetapi juga harus mudah dirawat, efisien, dan memberikan pengalaman menyenangkan bagi pengunjung.

Saat ini, saya terus memperdalam ekosistem web modern (HTML5, CSS3, JavaScript ES6+, dan Node.js dasar) serta selalu bersemangat untuk menyambut kesempatan praktik kerja lapangan (PKL), magang industri, maupun kolaborasi proyek web lainnya.
